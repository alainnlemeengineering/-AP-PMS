# AI-Powered Predictive Maintenance System (AP-PMS)

## Project Overview

AP-PMS is a machine learning-based predictive maintenance system designed to detect mechanical faults in electric motor bearings using vibration signal analysis.

The project combines mechanical engineering, signal processing, data science and artificial intelligence.

## Objectives

- Analyze vibration signals from electric motor bearings.
- Process signals using Python and SciPy.
- Extract statistical and frequency-domain features.
- Develop machine learning models for fault classification.
- Detect abnormal operating conditions.
- Evaluate model performance.
- Develop an interactive monitoring dashboard.
